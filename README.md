# Share Your Expenses

A mobile app for splitting expenses within groups, built with Flutter and Firebase.

## Features

- User registration and login
- Expense groups with multi-currency support
- Adding expenses (amount, description, date, receipt photo)
- Group member management
- Polish and English interface

## Stack

- **Flutter** 3.22 / Dart
- **Firebase** — Authentication, Firestore, Storage

## Running

```bash
cd share_your_expenses
flutter pub get
flutter run
```

> Requires Firebase configuration (`google-services.json` / `GoogleService-Info.plist`).
